# 本体 v2.1.1 で測った結果

この記録は、本体 v2.1.1 から指示文を作ったときの測定です。いまの指示文は本体 v2.2.2 から作り直し、[../README.md](../README.md) の測定で選びました。ここで選んだ決まりは、いまの指示文にも入っています。

本体（yomiyasu v2.1.1）と pocket の指示文に同じ文章を推敲させ、本体 v2.1.1 の検査で数えた結果です。指示文の候補を比べて決まりを選び、文末を依頼の形にそろえる前の指示文（候補 P2）を本体と比べました。v2.1.1 から作った最後の指示文（候補 Q1）は P2 の決まりを変えずに文末をAIへの依頼の形にそろえたものです（下の「Q1（v2.1.1 から作った最後の指示文）」の節）。本体と比べた表と合格の線の数字は、どれも P2 のものです。

## 条件

- 推敲させた道具: Codex CLI 0.162.1（`codex exec`）
- モデル: gpt-6-astra
- effort: high
- 設定: `--ignore-user-config` を付け、ふだんの設定と分けた測定用の CODEX_HOME で動かしました。プラグイン、メモリ、ウェブ検索、同梱と利用者のスキルは外しています。起動の形は [tools/run.py](../tools/run.py) の `CODEX_ARGV` にあります。
- 速さ: 最初は `service_tier` を `ultrafast` にして流し、途中から速さの指定をやめました（Codex の既定の速さ）。モデルと effort は同じです。本体の1回目と2回目（各115本）、P0、A0〜A5 は ultrafast、P1 は107本が ultrafast で8本が既定の速さ、P2 の3回と本体の3回目（各115本）はすべて既定の速さです。本体の3回目は、ultrafast で流した17本を既定の速さで流し直し、P2 と同じ設定にそろえました。どの文章をどちらの速さで流したかは、`results.json` の `service_tier` にあります。
- 途中で測定用のアカウントを替えました。モデルと設定は同じです。

## 残した決まりと外した決まり

- 意味を守る決まり（意味、文の働き、言い切りの強さ、数値、条件、否定、情報を足さない、分からない所を残す、文体と見出しや箇条書きの数と順）は、数字にかかわらず残しました。これらも例も入れない A0 では、意味が変わる恐れが83件、元のままの文章が0本、`human/` の書き換えた量の中央値が562.8でした。
- 「自然な文と慣用句は直しません。」は残しました。外した A1 では、意味が変わる恐れが10件（P0 は7件と6件）に、`human/` の書き換えた量の中央値が105.0に増え、元のままの文章が12本に減りました。
- AI らしい言い回しの例の並び（物や概念を人のように動かす比喩、「重要なのは」のような前置き、ほか）は残しました。外した A2 は意味が変わる恐れが2件でしたが、残った候補が50件で、元の原稿の49件より多く、候補を減らせていません。
- P1 の足しは P0 の pocket にだけ出た恐れを読んで決めました。読んだ恐れは名詞の句を条件の文に開いたもの、言い切りの文を依頼の文にしたもの、`human/` の文で文を落としたもの、かぎかっこの中の読点を消したものです。文の働きに「問い」を足し、「文も削りません」と「かぎかっこの中の言葉は保ちます」を足し、「言い直すだけのまとめ」の例を外しました。
- 「「仕様変更が」を「仕様が変わると」にするような、つながりを変える書き換えもしません。」を足しました。P1 の6件が P2 の1回目で2件になりました。P2 の3回は2件、3件、1件です。P1 はほとんどが ultrafast、P2 は既定の速さで流したので、この比べでは決まりの足しと速さの指定が同時に変わっています。
- コピー調と詰めた漢語の句の決まり（A3）は入れませんでした。意味が変わる恐れは6件、残った候補は42件で、P0（7件と6件、40件）より少なくなっていません。
- 比喩の動詞の例（A4）は入れませんでした。意味が変わる恐れは5件で P0 の2回（7件と6件）と大きく変わらず、残った候補は41件で P0 の40件より少なくなっていません。
- 紹介や宣伝の文の勢いを残す決まり（A5）は入れませんでした。1回の測定で意味が変わる恐れは3件、残った候補は39件でしたが、この文（24字）を P2 の383字に足すと407字になり、そのころの上限の400字を超えました。のちに指示文の長さを400〜500字にゆるめ、上限を500字にしましたが、A5 は1回しか測っていないので、Q1 にも入れていません。

## Q1（v2.1.1 から作った最後の指示文）

P2 には、「書き直してください」という依頼と、「付けません」「変えません」のような、書き手が自分のすることを述べた文のようにも読める文末がまじっていました。Q1 では指示文をすべてAIへの依頼の形にそろえました。あわせて、指示文の長さの決まりを400〜500字にゆるめ、生成のスクリプトと試験が止める上限を500字にしました。Q1 は413字です。

P2 から変えたのは次の4つです。決まりの中身は P2 と同じです。

- 文末を依頼の形（〜してください、〜しないでください）にした。「返すのは書き直した本文だけにし」も「書き直した本文だけを返し」にした。
- AIらしい言い回しの例の並びを1文にまとめた（「…など、AIらしい言い回しはふつうの言葉に直してください。」）。
- つながりの決まりの前に「ただし、」を足し、「書き換えもしません」を「書き換えはしないでください」にした。
- 「かぎかっこの中の言葉は保ちます」と「自然な文と慣用句は直しません」の「は」を「も」にした（「かぎかっこの中の言葉も保ってください」「自然な文と慣用句も直さないでください」）。

Q1 は P2 と同じ条件（Codex CLI の gpt-6-astra、effort は high、既定の速さ）で1回流しました。測定用のアカウントが利用額の上限に達したので、115本のうち34本で止まりました。その34本で、意味が変わる恐れは0件、書き直した文に残った候補は31件（同じ34本の元の原稿では39件）、元のまま返した文章は1本でした。34本の結果は `results.json` と `summary.json` には入れていません。

## pocket にだけ出た恐れ

P2 の3回で出た意味が変わる恐れ6件のうち、同じ原稿で同じ種類の恐れが本体の3回のどれにも出ていないものを「pocket にだけ出た恐れ」としました（[tools/aggregate.py](../tools/aggregate.py)）。5件あり、1件ずつ読みました。diff が数えた所では、どれも意味は変わっていません。ただし diff が数えない所で、P2 は書き手の言い回しも替えていました。2件目の原稿では「1メソッド」の次の文で「触る」が「修正する」に狭まり、`human/human_oga_08` では3回とも書き手の比喩と動詞（「全体の地図を頭の中に作る」「明示的に伝え」「前に進みます」）を別の言い方に替えていました。本体の3回はどれも元のまま残しています。読んだ記録は [pocket_only.json](./pocket_only.json) の `reading` にもあります。

残りの1件（P2 の1回目、`blacklist_ai/05_comparison_sonnet_casual` の「BFFを1枚挟む」を「BFFを1層設ける」にしたもの）は、本体の3回すべてにも同じ原稿で同じ種類の恐れが出ています。

1. P2 r1、`human/human_oga_08`、数の言い方が消えた（number / lost）
