# 測定の結果

本体（yomiyasu v2.2.2）と pocket の指示文に同じ文章を推敲させ、本体 v2.2.2 の検査で数えた結果です。いまの指示文は候補 C5 です。

本体 v2.1.1 から指示文を作ったときの測定は [v2.1.1/README.md](./v2.1.1/README.md) にあります。いまの指示文の決まりの多くは、そのときの比べで選んだものです。

- モデル: gpt-6-astra

- 設定: `--ignore-user-config` を付け、ふだんの設定と分けた測定用の CODEX_HOME で動かしました。プラグイン、メモリ、ウェブ検索、同梱と利用者のスキルは外しています。起動の形は [tools/run.py](./tools/run.py) の `CODEX_ARGV` にあります。

- 意味が変わる恐れ: 元の原稿と書き直した文を、本体 v2.2.2 の `yomiyasu_diff.py --fail-on meaning-risk`（文書の種類は指定しない）で比べた `fail_on_meaning_risk_count` です。

## 類例での読み比べ

本体 v2.2.0 を作るときに作られた類例10本で、候補を比べました。直訳語の類例4本と、見出しの比喩、「と言えるでしょう」、意味の薄いカタカナ語、評価を言い直すだけの文の類例6本です。どの類例にも、直すべき文（fix）と残すべき文（keep）の印が付いていて、10本で129か所あります。類例の文書は、このリポジトリには入れていません。

候補を1回ずつ、上と同じ条件で流しました。3つの候補の書き直しを名前を伏せて並べ、Claude（claude-opus-5-5）が印ごとに次の3つのどれかを付けました。別の Claude が「直せていない」と「害がある」の判定をすべて読み直し、変えた判定は0件でした。

- よい: 直すべき文を、誰が何をするかが読める文に、原文と前後の文にある名前と動作だけで書き直した。原文に書いていない中身を尋ねるべき文なら、原文のまま残してもよいとしました（pocket は書き手に尋ねられないため）。残すべき文では、その言い方を残した。
- 直せていない: 直すべき文を直さなかったか、直しになっていない言い換えをした。
- 害がある: 意味を変えた、原文にない名前や動作を足した、意味の広い語（影響する など）に替えただけ、または残すべき言い方を書き換えた。

C5 の「害がある」8か所は次のとおりです。

- 「利用者にとっての針をほとんど動かしません」を「利用者にとってはほとんど改善になりません」にし、「改善」という向きを足した（C0 と C4 は「影響しません」にした）。
- 定着した言い方の「集計のクエリを流します」を「実行します」にした（C4 も同じ）。
- 読み物の見出し「来客」を「虫」に、宣伝文の見出し「夜ふかし係」を「照らす範囲と明るさ」にした（C4 も同じ。「夜ふかし係」は C0 も書き換えた）。
- 「コミットメント」を「積極的な関わり」にし、読み手が何をするかは書かないまま言い換えた（C4 も別の言い方に替えた）。
- 定着した「マイルストーン」を3か所とも「節目」にした（C0 も同じ。C4 は残した）。

C4 と C5 の違いは「数え方」の4字だけで、「マイルストーン」の3か所の差は、1回ずつ流した出力の違いです。C0 の数は、3回の読み比べ（C0、C1、C2 と、C0、C1、C4 と、C0、C4、C5）で、同じ出力に対して86、85、86件が「よい」でした。読み比べのすべての数は [seed.json](./seed.json) にあります。

## pocket にだけ出た恐れ

C5 の3回で出た意味が変わる恐れ1件は、同じ原稿で同じ種類の恐れが本体の3回のどれにも出ていないので、「pocket にだけ出た恐れ」です（[tools/aggregate.py](./tools/aggregate.py)）。読んだ記録は [pocket_only.json](./pocket_only.json) の `reading` にもあります。

1. C5 1回目、`raw_ai/06_spec_draft_sonnet_casual`、数の言い方が増えた（number / added）
   - 元（5 行目）: 間隔は初回30秒から始めて倍々に伸ばし、上限は1時間とする。
   - 後（5 行目）: 間隔は初回30秒から始めて2倍ずつ延ばし、上限は1時間とする。
   - 読み: 「倍々に伸ばし」を「2倍ずつ延ばし」にしたので、diff が数の言い方の増えとして数えた。初回の30秒から1回ごとに2倍にする意味は同じで、上限の1時間も残っている。「伸ばし」を「延ばし」にした表記の替えもあるが、間隔を長くする意味は変わらない。
